## 构建与修改

已验证的环境为 Windows、PowerShell 7、Tectonic 0.17.0。使用 Tectonic 的 XeTeX 后端，中文字体采用 TeX 发行包中的 Fandol，无需安装额外商业字体。首次编译需联网下载宏包和字体，后续复用本地缓存。

在仓库根目录运行：

```powershell
pwsh -File tools/latex/build.ps1
```

若 Tectonic 未加入 PATH，可指定可执行文件位置：

```powershell
pwsh -File tools/latex/build.ps1 -TectonicPath 'C:/tools/tectonic/tectonic.exe'
```

构建直接更新两本 PDF，缓存写入 Git 忽略的 `tmp/latex-runtime/cache/`。排版参数位于每本完整源文件的导言区；修改公共风格时同步两份导言区。正文不依赖任何分章文件。内容变更后应重新核验数学推导、编译日志、目录引用及受影响页面，标准见 [AGENTS.md](../AGENTS.md)。

原始资料仅保留在本地 `参考资料/`，不随仓库上传。资料与编写说明、题干疑点均收录在两册书末。
