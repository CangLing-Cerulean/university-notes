## 文档组织

每门课程分为“知识讲义与例题”和“期末真题与解析”两部分，两部分使用相同的章节顺序。每章使用 `01-主题名称.md` 和 `01-主题名称.pdf` 配对命名。配套插图放在课程内的 `assets/` 目录，课程首页维护章节、文件链接和审核状态。

## 整理标准

1. 根据资料建立知识结构，明确符号、前置知识与适用条件。
2. 审核定义、定理、公式、量纲、推导和例题答案，保留必要的中间步骤。
3. 补充帮助理解的解释、例题与易错点，注明补充内容依据。
4. 在章节末列出可追溯的来源；资料冲突或证据不足时标为“待核实”。
5. 从同一版 Markdown 导出 PDF，核对内容一致性并检查公式、中文、图表与分页。
6. 更新课程目录，再提交审核完成的 Markdown、PDF 和配套素材。

正文按内容需要组织，不强制添加空章节。课程知识文档同时提供 Markdown 和 PDF，导航页与整理规范仅保留 Markdown。

## 内容审核与发布

“待核实”内容不作为已确认结论。纠正原资料中的实质错误时，在相关位置说明原说法、修正结果与依据。

发布内容以自行整理的知识笔记为主，引用标明出处。原始资料仅保留在本地 `参考资料/` 目录，该目录由 Git 忽略，不上传到 GitHub。
