## 文档组织

每门课程分为“知识讲义与例题”和“期末真题与解析”两部分，两部分使用相同的章节顺序。课程正文只保留两本完整文档的 `.tex` 和 `.pdf`，不保留旧版、样章或分章文件。LaTeX 源文件自包含，数学图示直接绘制；课程入口维护文件链接、构建方法和审核状态。

## 整理标准

1. 根据资料建立知识结构，明确符号、前置知识与适用条件。
2. 审核定义、定理、公式、量纲、推导和例题答案，保留必要的中间步骤。
3. 补充帮助理解的解释、例题与易错点，注明补充内容依据。
4. 在章节末列出可追溯的来源；资料冲突或证据不足时标为“待核实”。
5. 从同一版 LaTeX 编译 PDF，核对内容一致性，渲染并逐页检查公式、中文、图表与分页。
6. 更新课程目录，再提交审核完成的 LaTeX、PDF 和配套素材。

正文按内容需要组织；缺少真题的章节如实说明资料缺口。修改直接更新完整 LaTeX 源文件，并重新生成对应 PDF。

## 内容审核与发布

“待核实”内容不作为已确认结论。纠正原资料中的实质错误时，在相关位置说明原说法、修正结果与依据。

发布内容以自行整理的知识笔记为主，引用标明出处。原始资料仅保留在本地 `参考资料/` 目录，该目录由 Git 忽略，不上传到 GitHub。
